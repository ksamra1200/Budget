# Budget

A simple monthly budgeting app. Set a budget per category, log income and
expenses, and see how you're tracking at a glance. All data is stored
locally in your browser (`localStorage`) — nothing leaves your machine.

## Features

- Monthly budget by category, with progress meters (on track / near limit / over budget)
- Income and expense log, filterable by month
- Month navigation to review past or plan future months
- Add, edit, and remove categories

## Getting started

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

## Build

```bash
npm run build
```
